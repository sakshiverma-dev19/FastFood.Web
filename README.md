# 🍔 FastFood.Web – Online Food Ordering Application

## About Project
FastFood.Web is an online food ordering web application developed using ASP.NET Core MVC. This project was created for learning and practicing web application development.

## Technologies Used
- ASP.NET Core MVC (.NET 8)
- C#
- Entity Framework Core
- SQL Server
- HTML
- CSS
- Bootstrap
- JavaScript

## Features
- User Registration and Login
- User Authentication
- Food Items Management
- Food Categories
- Shopping Cart
- Checkout
- Payment Module
- Database Management using Entity Framework Core

## Database
- Database: FastFoodDb
- SQL Server
- Entity Framework Core

  ## Database Setup

1. Open SQL Server Management Studio.
2. Open the Database folder.
3. Execute FastFoodDb.sql.
4. Update the connection string in appsettings.json.
5. Run the application using Visual Studio 2022.

## Project Structure
- Controllers
- Models
- Views
- Data
- Repository
- Services
- wwwroot

## How to Run the Project

1. Clone this repository.
2. Open the solution in Visual Studio 2022.
3. Update the SQL Server connection string in `appsettings.json`.
4. Create the database using the provided SQL script or Entity Framework migrations.
5. Run the application.

## Purpose
This project was developed for learning and improving practical skills in ASP.NET Core MVC, C#, Entity Framework Core and SQL Server.
